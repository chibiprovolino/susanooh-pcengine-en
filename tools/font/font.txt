# Susano-O Densetsu English font: an original 1bpp design for this patch (docs/design.md).
# Compile with tools/font/fontc.py (widths.json, VWF bank $61, fixed 8x12 glyphs for the original putc).
#
# Block format:
#   glyph <hex code> <name> <advance> [keep]
#   then 16 rows of 8 columns ('.' blank, '#' ink); row 0 = top of the 8x16 text cell, MSB = left column.
# advance = ink width + 1 px spacing (max 8). VWF glyphs start at column 0.
# Metrics (cell rows): ascender 2, cap height 9 (3-11), x-height 6 (6-11), baseline under row 11,
#   descenders 12-14. Digits share one advance (6). Rows 0, 1 and 15 stay empty.
# Codes 0x20-0x5A are also compiled to fixed 8x12 cells (cell rows 2-13, ink centred) and must keep
#   their ink inside rows 2-13. "keep" glyphs are the game's own (rows 2-13 copied from the ROM,
#   checked by fontc.py) and are never redrawn: cursors, placeholders, password-grid marks.
# Byte table (§5): 0x20-0x5A ASCII, 0x61-0x7A a-z (VWF only), 0x22 = left double quote,
#   0x7C = right double quote, 0x27 = apostrophe / right single quote, 0x60 = left single quote,
#   0x7B = ellipsis, 0x7D = em dash, 0x28/0x29 = ( ).
